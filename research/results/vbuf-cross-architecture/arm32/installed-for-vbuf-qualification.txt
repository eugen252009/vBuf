# Alpine ARM32 qualification installation record

Target: `cubietruck-plus` via `ssh alpine`
OS: Alpine Linux 3.24.1, armv7 repository

The board clock initially read 1970-01-01. TLS package/crate downloads were
blocked until the clock was synchronized with NTP:

```sh
ntpd -q -n -p pool.ntp.org
```

The initial HTTPS APK repository also reported an untrusted/not-yet-valid
certificate. The minimal package installation used temporary HTTP repository
overrides, not a broad system upgrade:

```sh
apk add --no-cache \
  --repository http://dl-cdn.alpinelinux.org/alpine/v3.24/main \
  --repository http://dl-cdn.alpinelinux.org/alpine/v3.24/community \
  ca-certificates rust cargo build-base
apk add --no-cache \
  --repository http://dl-cdn.alpinelinux.org/alpine/v3.24/main \
  curl
```

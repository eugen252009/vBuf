Reference boundary from the pinned DeepSeek implementation:

```text
block input [2048, position]
→ attn_norm RMSNorm(epsilon=1e-6)
→ MLA_NON_SPLIT_KV attention
→ attention output projection
→ attention residual add
→ exact attention residual is ffn_inp
→ ffn_norm RMSNorm(epsilon=1e-6)
→ real router matmul [64]
→ softmax and deterministic top-k 6
→ selected-probability normalization
→ six routed expert SwiGLU FFNs
→ weighted routed merge
→ shared expert SwiGLU FFN
→ routed + shared
→ FFN residual add
→ complete block output [2048, position]
```

There is no scale, add, or normalization between the POC14 attention residual
and the POC13 `ffn_inp` boundary. POC15 composes the existing `compute_token`
and `run_layer` paths; it does not add a block-specific runtime executor.

Fixtures are F32 `[2048,1]` vectors generated by the existing deterministic
`one_hot(0, 2048)` and `one_hot(1, 2048)` helpers. Positions are 0 and 1.
Attention state is two generic append-only slots: K `[16,192]` and V
`[16,128]`, retained between the sequential token executions and kept outside
the model artifact.
